# Paiva & Paiva — site institucional

Primeira versão de um site institucional simples e elegante para **Paiva & Paiva Advocacia e Assessoria Jurídica**.

## Stack
- HTML5
- CSS3
- Tailwind CSS via CDN
- JavaScript vanilla mínimo, apenas para rolagem suave
- Sem React
- Sem npm
- Sem build step

## Estrutura

```text
paiva-paiva-site/
├── index.html
├── styles.css
└── assets/
    ├── maria-elizabeth.png
    ├── ana-paula.png
    └── referencia-instagram.png
```

## Antes de publicar

1. Substituir os placeholders de WhatsApp e e-mail em `index.html`.
2. Conferir nomes, cargos, números de OAB e demais dados profissionais.
3. Definir o domínio e as URLs oficiais das redes sociais.
4. Substituir/ajustar textos conforme a atuação efetiva do escritório.
5. Se necessário, trocar as fotos por arquivos originais em maior resolução.

## Direção visual

A referência original usa fundo escuro, preto e dourado. Nesta versão, a linguagem foi mantida, mas invertida:
- fundo marfim/creme como base;
- dourado champanhe como acento;
- preto/grafite apenas em títulos, navegação e uma seção de contraste;
- areia e verde-sálvia muito suaves para criar profundidade;
- serifada editorial para títulos;
- sans-serif limpa para textos e navegação.

A proposta é transmitir sofisticação sem deixar o site pesado ou excessivamente "luxuoso".
